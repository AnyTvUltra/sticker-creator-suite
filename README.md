# Sticker Creator Suite

سويلي تطبيق ويب ساغلفه فيما بعد الى ملف exe ، أن يكون هناك انشاء ستيكرات او ورقة بحجم A7 بتصميم جميل مثلا اسم المنتج والموديل واللون والحجم والمواصفات والضمان والباركود ، ايضا امكانية تعديل المنتج عبر البرنامج واعادة طباعة الورقة 

مع امكانية السحب والافلات لتصميم الورقة بشكل مباشر بشكل جميل ، اضافة اللغة الكوردية السورانية ايضا
